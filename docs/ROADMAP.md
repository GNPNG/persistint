# Roadmap

What's coming, by version. Dates are estimates. Updates arrive as minor versions (0.3.0, 0.4.0, ...);
fixes within a version are patches (0.3.1). Right now they're frequent; over time they'll spread out.
Some items carry a code name until they ship.

## v0.4.0 (minor)

- Touch controls: tap icons for the wardrobe, the journal and help, so it plays on a tablet with
  no keyboard.
- The clone children's remaining lines in their own voices.

## Later (dates to follow)

- Paper look: paper edges and shadows across the world, a zoom-out for the ship's crowded decks,
  and a cute overhead map.
- Classroom path: a guided 30-minute route through the game with a teacher's sheet.
- Butterscotch.
- Pedestal.
- Open Mic.
- Stable Voices.
